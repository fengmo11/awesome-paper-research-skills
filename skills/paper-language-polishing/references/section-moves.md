# Section Moves

## Abstract

Context -> gap -> approach -> key result -> implication -> boundary.

Style: compact, evidence-specific, and bounded. Put the result before the broad
implication.

Top-journal default: one continuous paragraph unless the target venue explicitly
requires a structured abstract.

## Introduction

Field stake -> unresolved bottleneck -> prior attempts -> remaining gap -> present study.

Style: move from field need to precise gap quickly. Do not turn related work
into a chronological list.

Top-journal default: avoid fine-grained subheadings in the Introduction unless
the venue or article type expects them. Build the gap paragraph by paragraph.

Final paragraph: present study -> core method or data -> contribution -> what
evidence will decide the claim.

## Related Work

Concept group -> representative work -> limitation for this paper's question -> how the present study differs.

Style: group by problem, assumption, dataset, task, method, or evaluation axis.
Avoid vague statements that prior work "fails" unless directly supported.

## Results

Question -> action -> quantitative result -> evidence -> short interpretation.

Style: lead with the test, then the finding. Keep interpretation short and avoid
Discussion-level claims.

Results subheadings should ideally be declarative logical steps, not generic
labels such as "Experiment results".

## Methods

Design rationale -> procedure -> parameters -> reproducibility detail -> quality control.

Style: precise procedural verbs, past tense for completed work, present tense
for reusable definitions. Do not interpret results here.

## Discussion

Main advance -> interpretation -> relation to prior work -> limits -> future use.

Style: synthesize rather than repeat results. Use stronger hedging than Results.
Address alternative explanations before reviewers do.

## Conclusion

Main contribution -> decisive evidence -> implication -> boundary.

Style: short, scoped, and free of new evidence.

## Limitations

Limitation -> why it matters -> effect on interpretation -> mitigation or future work.

Style: specific and honest. Do not use generic limitation language when a more
precise constraint is known.

## Cover Letter

Paper title -> venue fit -> core contribution -> evidence summary -> reader value -> compliance notes.

Style: editor-facing, concise, and factual.

## Rebuttal

Acknowledgement -> action taken -> evidence/location -> remaining boundary.

Style: respectful and traceable. No promised change should be absent from the
revised manuscript.
